# Sketchfab Poly Count Display 🎨

A high-performance Tampermonkey UserScript that displays triangle counts (tris) on Sketchfab thumbnails.

> **Why this script?**
> Sketchfab doesn't show model weight/complexity on the search page. This script adds that info instantly, helping you find optimized models faster.

## Features 🚀

- **🛡️ Anti-Ban System:** Uses a smart queue to prevent IP bans.
- **⚡ Internal API:** No personal API Token required.
- **🎨 UI Smart Fixes:** Badges automatically hide behind popups and search overlays.
- **📉 Visual Indicators:**
  - 🟢 **Green:** Low Poly (< 50k)
  - 🟠 **Orange:** Mid Poly (< 200k)
  - 🔴 **Red:** High Poly (> 200k)

## How to Install 📦

1. First, install **Tampermonkey** extension for your browser:
   - [Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) | [Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/) | [Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)

2. **Click the button below to install the script:**

[![Install Script](https://img.shields.io/badge/INSTALL_SCRIPT-CLICK_HERE-brightgreen?style=for-the-badge&logo=tampermonkey)](https://github.com/WemooNN/Sketchfab-poly-count/raw/refs/heads/main/sketchfab-poly-count.user.js)

3. Go to [Sketchfab](https://sketchfab.com) and start browsing!
